# Bakebook assets

- mascot.png: generated with the built-in ImageGen tool from the selected Bagel Log bakebook mock. Prompt: preserve the smiling sesame bagel baker, chef hat, pencil, notebook reading Good Bagels Happier Days, and heart; isolate the character and notebook on a transparent square canvas; omit app UI.
- fraunces.ttf: https://github.com/google/fonts/tree/main/ofl/fraunces (OFL; see FONT-LICENSE.txt).
- SVG icons: https://github.com/tabler/tabler-icons (MIT; see ICON-LICENSE.txt).

Fonts, icons and mascot are stored locally for offline use. User batch photos stay in IndexedDB and are not part of these assets.
